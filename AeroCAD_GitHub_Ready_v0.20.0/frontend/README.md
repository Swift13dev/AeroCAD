# AeroCAD Frontend

React + Vite client for the AeroCAD urban cadastral mapping and verification workflow.

## Run

```bat
npm install
npm run dev
```

Or use:

```bat
start-frontend.bat
```

The Vite dev server runs on `http://127.0.0.1:5174` and proxies `/api` requests to `http://127.0.0.1:8000`.

## Build

```bat
npm run build
```

The application intentionally uses a restrained, Figma-style visual system with custom CSS rather than a generic dashboard template.
